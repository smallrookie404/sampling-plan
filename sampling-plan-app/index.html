使用说明

这个软件做什么

复刻《0.系统测点布局调查2025.12.19（6）.xlsx》的全部功能：录入现场调查信息后，右侧自动生成标准化的采样计划字段（检测项目规范名、班制、每班人数、采样类别、检测方式、检测天数、每天样品数、委外检测、粉尘性质、危害来源等），并实时校验填写是否正确。

操作步骤

  1. 在「测点布局调查」页填写左侧录入区（白色列），右侧灰色列为自动计算结果；
  2. 黄色列（岗位性质、接触类型、是否采样/测量、检测方式）可在下拉中选择覆盖自动值，选择「（自动计算）」即恢复；
  3. 自动计算区最后一列「备注」默认按检测项目自动生成，也可直接点击单元格手动编辑（编辑后保留手动内容，清空则保持为空）；
  4. 接害因素输入时有联想提示，名称必须能在「危害因素库」中查到；
  5. 点击行号可选中整行，用工具栏按钮新增/插入/复制/删除行；
  6. 录入区支持 Excel 式编辑：点击单元格定位（显示高亮框），方向键移动光标，Enter 下移、Tab 右移（Shift+Enter/Tab 反向），F2 或双击进入编辑，直接输入会替换原内容，Delete/Backspace 清空选中的内容、Esc 还原；Shift+方向键、Shift+点击或拖动可扩展选择区域，Ctrl+A 全选整张表，Ctrl+C 复制、Ctrl+V 粘贴 Excel 表格内容（粘贴时按行列规律重复填充到整个选中区域，复制单个内容则整片选中区域全部填入）；「清空录入区」可一键清除全部录入内容；
  7. 新增/插入/复制/删除时可输入自定义行数，批量操作；
  8. 「保存数据」可为当前数据命名并保存到项目文件夹的 data\records.json；「数据记录」中可按名称或内容搜索，一键调用（替换当前表格），减少重复录入；
  9. 部署到静态网页（GitHub Pages）时，点「GitHub 配置」填写仓库与 Token，保存的数据与参考库将直接写入 GitHub 仓库中的 records.json / library.json；
  10. 配置 GitHub 后（本地版或网页版均可），软件打开时自动从 GitHub 同步最新数据，保存时直接写回 GitHub，本地文件仅作离线兜底；
  11. 「危害因素库」「检测项目参考」页可维护字典（新增、删除、搜索），修改后主表自动重算，并自动同步保存（本地版存到 data\library.json，GitHub 版直接写回仓库）；
  12. 点「导出 Excel」生成只包含自动计算区（W~BI 共 39 列）的交付文件，行数到「检测项目」列最后一个非空单元格为止；「导入 Excel」可载入该导出文件，也可载入原表结构的完整文件继续编辑。
  13. 点工具栏「⛶ 全屏」可将表格放大到浏览器全屏，导入、导出、保存等操作按钮浮动在表格顶部，按 Esc 或点「退出全屏」返回；

自动计算规则（与原表公式一致）

  • 单元/工作场所、岗位/工种、点位、人数、周天数、日接触时长等：同一岗位只填首行，空白自动继承上一行；
  • 岗位性质缺省「固定」，作业方式缺省「半手工作业」，检测方式缺省「定点」，是否合岗缺省「否」；
  • 检测项目：接害因素经危害因素库自动规范为系统内名称；
  • 每班最大人数＝岗位总人数 ÷ 班制数（五班=5、四班=4、三班=3、两班=2），向上取整；
  • 班制/班制数：同车间同岗位自动回填，缺省「单班 / 长白班」；
  • 检测天数：游离二氧化硅、噪声、高温、工频电场、手传振动、高频电磁场、紫外辐射、有机组分定性→1 天，其余沿用录入的检测天数；
  • 每天样品数：有机组分定性/个体采样/游离SiO₂/工频电场/高频电磁场→1；噪声/高温/手传振动→3；紫外辐射→1；日接触 0.5h→2、0.25h→1、其他→3；
  • 采样时间类型：定点→短时间、个体→长时间；噪声源：同岗位存在个体噪声采样→是；危害来源：噪声/高温/紫外辐射→设备运行，否则原辅物料。

提示：导出文件仅含自动计算区，供采样计划交付使用；数据记录以 data\records.json 保存在项目文件夹中，可在「数据记录」页导出 JSON 备份，请定期备份。

GitHub 在创建 Token 时仅显示一次，之后网页上无法再查看；本软件会将 Token 保存在本机浏览器中，重新打开配置时会自动填入，无需重复输入。如换浏览器或换电脑，请重新创建 Token 后填写。
